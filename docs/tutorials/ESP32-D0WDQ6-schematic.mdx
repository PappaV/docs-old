## Overview

This tutorial provides a **schematic‑only** view of a simple ESP32‑D0WDQ6 module circuit. It mirrors the example from the Hardware Academy tutorial, focusing on the essential connections without a PCB layout.

## Schematic

![ESP32‑D0WDQ6 Schematic](../../static/img/ESP32-D0WDQ6/schematic.png)

The schematic shows:
- Power supply (3.3 V) connection to the ESP32 module.
- Decoupling capacitors.
- Basic UART pins (TX0/RX0) for serial communication.
- A reset button and EN (enable) pin.
- Optional external crystal if required.
